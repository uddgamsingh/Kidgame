# 🎈 Fun Games for Kids

## Voices
The talking voices come from the phone/computer itself. Tap **🔊 Voice** on the home screen to try other voices on the device.
On iPhone: Settings > Accessibility > Spoken Content > Voices > English, download an "Enhanced" or "Premium" voice.
On Android: Settings > Text-to-speech, install the Google voice.
Animal and funny sound effects are made by the page itself, so they sound the same everywhere.
