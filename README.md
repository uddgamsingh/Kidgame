# 🎈 Fun Games for Kids

49 free games for ages 3–8 in a single `index.html` (no build, no dependencies).

Talking cat (listens and repeats in funny voices), colouring with brushes, magic draw, animal sounds,
memory match, fireworks, fishing, ABC, counting and more.

## Host on GitHub Pages
1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute your game is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- The cat's microphone needs the page to be served over **https** (GitHub Pages is) and the browser to allow the mic.
  Works in Chrome, Edge and Safari. If the mic is blocked, kids can type a word or tap a picture.
- Funny voices use the device's built-in text-to-speech, so they sound a little different on each device.

## Secret offline mode (only you know)
There is no visible button. **Tap the spinning ☀️ at the top of the home screen 5 times quickly.**
- First time: a toast says "✈️ Offline mode ON". The page and fonts are saved in *that browser*, so it opens with no internet (flights!).
- Tap the sun 5 times again: "🌐 Offline mode OFF". The saved copy is deleted and the page needs internet again.
- It only affects the browser you do it in. Other visitors never get offline mode unless they know the secret.
- Upload **both** `index.html` and `sw.js` to the same folder. Needs the https GitHub Pages link.
- Tip: switch it ON while you have internet, open the page once, and then it will also open in airplane mode.

## Voices
The talking voices come from the phone/computer itself. Tap **🔊 Voice** on the home screen to try other voices on the device.
On iPhone: Settings > Accessibility > Spoken Content > Voices > English, download an "Enhanced" or "Premium" voice.
On Android: Settings > Text-to-speech, install the Google voice.
Animal and funny sound effects are made by the page itself, so they sound the same everywhere.
